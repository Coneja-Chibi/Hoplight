# Kit reference

Kit is Hoplight's conversational terminal surface. It uses the same canonical entities and Studio
store as the Web UI.

- [Content tools](tools.md) documents the capability catalog, progressive model exposure, and the
  implemented canonical content bundles.
- Kit can search and read catalog-declared Hoplight user and developer documentation through the
  read-only `docs_query` model tool.
- [UI reference](../ui.md#kit-terminal-shell) documents the terminal behavior users can run today.
- [Architecture](../architecture.md#semantic-content-capabilities) documents ownership and
  dependency direction.
